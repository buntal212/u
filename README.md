# Udumbara Internal Hub

Laravel backend foundation for UIH. M1 provides an isolated Docker development and testing environment, Laravel 13 on PHP 8.3, MySQL 8.0.40, PHPUnit, Pint, and `GET /api/v1/health`.

M1 contains no business features or domain tables. Read [Docker development](docs/engineering/DOCKER_DEVELOPMENT.md) and [testing](docs/engineering/TESTING.md) for setup and daily commands. Project-specific agent workflow is in [AGENTS.md](AGENTS.md); portable skills are in `.agents/skills/`.
